# odin-recipes

My first project from The Odin Project: a simple recipe website built with HTML.

## What I practiced

- HTML boilerplate and page structure
- Headings, paragraphs, and lists
- Links between pages using relative paths
- Images with alt text and dimensions
- Git workflow with atomic commits
